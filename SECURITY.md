# Security Policy

| Version | Supported          |
| :---    | :---               |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Security and integrity are paramount in financial software. If you discover a potential vulnerability, concurrency flaw, or race condition in **Ledger Core**, please report it responsibly.

- **Do NOT** open public issues for security vulnerabilities.
- Please email security disclosures privately to: **security@ledgercore.ke** or utilize GitHub Private Vulnerability Reporting directly in the repository's [Security Advisories](https://github.com/crnjihia/ledger-core/security/advisories) tab.

### What to Include:
- Description of the vulnerability.
- Step-by-step instructions or cURL scripts to reproduce the issue.
- Potential impact on balance consistency or data privacy.

We commit to acknowledging your disclosure within 48 hours and providing a remediation timeline.
